# Contributing

Thanks for helping! To keep the list accurate, all changes to MetalDex are made by the maintainer. You don't need to
edit any files: tell us what's missing or wrong, and it gets checked and added.

Open an issue and pick the form that fits (**Issues → New issue**):

| Form | Use it for |
| --- | --- |
| **New figure or release** | A figure that isn't listed, a newly announced design, or a re-release |
| **Fix a figure** | A wrong name, date, photo, sales channel or note |
| **Photo submission** | Your own photo of a figure (you're credited on it) |
| **Wrong match** | A sale counted for the wrong figure (use the **Wrong figure?** link next to the sale in the tracker) |
| **Photo removal or credit change** | For owners of a photo shown in the tracker |

## Sources

The goal is a list people can trust, so please add a link if you can: an official announcement, the Square Enix
e-STORE page, a shop listing, or a news article. Japanese sources are ideal. If you're not sure about something, say
so; a report without a source is still useful and will be looked into.

## Photos

Many figures only have a shop photo, and many prize figures have none. Clear photos of a single figure on a plain
background, at least 600 px, help the most. Use the **Photo submission** form and drag the image in.

By submitting a photo you confirm you took it and agree it can be shown in this project under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) with your name as credit.

## Pull requests

This project doesn't take pull requests; please use the forms above instead. See `SECURITY.md` to report a security
problem privately.
